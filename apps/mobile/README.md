# Yaqeen mobile (Flutter · iOS + Android)

## Run

```bash
cd apps/mobile
# native projects are committed (bundle id com.yaqinbrand.yaqeen); iOS needs ios/Flutter/Secrets.xcconfig
cp ios/Flutter/Secrets.example.xcconfig ios/Flutter/Secrets.xcconfig   # Google iOS client ids
flutter pub get
flutter gen-l10n
# Android emulator reaches your machine at 10.0.2.2
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:4000 --dart-define=FLAVOR=dev
flutter test
```

Flutter ≥ 3.24, Dart ≥ 3.5.

## Structure

```
lib/
  app/            router (go_router, 5-tab StatefulShellRoute), shell
  core/
    config/       Env (--dart-define)
    di/           Riverpod providers — the only place dependencies are wired
    network/      ApiClient (JSON, bearer, one transparent refresh), TokenStore
    offline/      Outbox — persistent FIFO of writes, replayed with clientEventId
    storage/      KvStore (prefs / secure / memory)
    analytics/    Analytics + AdEvent allowlist (mirrors packages/contracts AD_EVENTS)
    notifications/ NotificationPlanner (pure), LocalNotificationScheduler, PushService
    theme/ widgets/  design system: tokens, typography, LiquidGlass, YqIcon, controls
  features/<name>/
    domain/       pure Dart models + logic (unit-tested)
    data/         repositories (API + cache)
    presentation/ screens + controllers
  l10n/           app_ar.arb (template) · app_en.arb
```

Each feature folder has a README with its screens, what is built and what is next.

## Rules that are easy to break

- **Western digits** everywhere (`YqFormat.number`), Arabic RTL by default.
- **Brand:** logo only via `YqLogo` (artwork in `assets/brand`, regenerated by `packages/brand/scripts/generate.py`). Light splash built from the logo artwork; brand gradient (`YqBrand.gradient`) for premium moments only; content screens stay porcelain, no geometric ornament.
- **Icons & native splash:** `python3 packages/brand/scripts/generate.py && python3 -I packages/brand/scripts/install_native.py` installs the app icons and the porcelain + navy-mark launch screens into `android/` and `ios/`.
- **Religious content** (azkar, duas) comes only from reviewer-approved items: `assets/content/seed.json` is written by `pnpm --filter @yaqeen/api content:export`, never by hand.
- **Worship data never leaves for ads.** Only `AdEvent` values can reach ad SDKs, and only with the `ads_measurement` consent.
- **Writes go through the Outbox** when they must survive offline (challenge tasks).
- Presentation never calls `ApiClient` directly — go through a repository provider.

## Wired platform integrations

Local notifications (`PluginLocalNotifier`), location + compass, Google/Apple sign-in, connectivity,
wakelock/share/url launcher, ATT, and audio (`JustAudioEngine`: just_audio + just_audio_background,
`audio_session`) are overridden in `main.dart`. Tests use the fakes in `core/platform`.

## Native integrations (phase 2)

Each sits behind an interface in `core/` with a no-op default, so the app runs without them. Add the package, implement the adapter, override the provider in `main.dart`.

| Interface | Package(s) | Notes |
| --- | --- | --- |
| `PushService` | firebase_core, firebase_messaging | Register token via `POST /v1/me/devices`; Android 13+ needs POST_NOTIFICATIONS |
| `RecitationEngine` | on-device ASR (whisper.cpp / ONNX) | `recite` flag stays off until ≥ 90 % word accuracy (spec §6.8) |
| `AdSink` | Firebase Analytics (Google Ads), facebook_app_events, TikTok Business SDK, app_tracking_transparency | Only after consent; ATT prompt on iOS only after in-app opt-in |
