# Yaqeen brand assets

Source: **Yaqeen Brand Identity 2026** (13-page PDF) and the designer's export folder. Originals are in `source/`
(renamed); everything else is generated by `scripts/generate.py`. Don't edit the generated files by hand.

```bash
python3 packages/brand/scripts/generate.py   # needs Pillow; also copies assets into apps/mobile and apps/admin
```

## Logo

| File | Use |
| --- | --- |
| `logo/mark-navy.png` · `mark-white.png` | The symbol alone — an abstracted «ن» with a gold diamond. App icon, favicon, small spaces. |
| `logo/lockup-stacked-*.png` | Mark above «يقين» + «Yaqeen». Splash, onboarding, about. **Primary lockup.** |
| `logo/lockup-horizontal-*.png` | Mark beside the bilingual wordmark. Headers, dashboard sidebar. |
| `logo/lockup-ar-*.png` · `lockup-en-*.png` | Single-language versions. |
| `logo/tile-*.png` | Square tiles for social profile images. |

- Navy version on light backgrounds; white version on the brand gradient / navy. The gold diamond and gold diacritics stay gold in both.
- Clear space: the height of the gold diamond on every side. Minimum width: mark 24 px, lockup 96 px.
- Never retype the logo in a font, recolour the gold, add effects, or place it on photos without enough contrast.

## Colour

| | Hex | Role |
| --- | --- | --- |
| Midnight | `#0A1530` | Logo navy, primary text, gradient start |
| Navy | `#10214D` | Gradient middle, dark surfaces |
| Lapis | `#1F3F94` | Accent (buttons, links, active states), gradient end |
| Sky | `#8FB0E0` | Soft accent, charts |
| Gold | `#C6A867` | Diamond, diacritics, rewards. For gold **text** on light backgrounds use `goldText #7C6127` (contrast). |

Tints (15) and the gradient live in `packages/design-tokens/tokens.json`.

Brand gradient: `#0A1530 → #10214D → #1F3F94`, dark at the start. Used for the app icon and a few premium surfaces.
The splash is **light**: porcelain `#F7F9FC` with the navy **mark only** — split by colour into wings and gold diamond
(`logo/splash-*.png`) so they animate separately and recombine exactly. Reading and worship screens stay porcelain too.

## Type

ZEYADA Arabic 1 (Arabic headlines) and Canela Text (Latin headlines) — see `fonts/README.md` for licensing.

## App icons

| Platform | Files | Where they go |
| --- | --- | --- |
| iOS | `app-icon/ios/AppIcon-1024.png` (+ `-dark`, `-tinted` for iOS 18) | Xcode → Assets → AppIcon (single size) |
| Android | `app-icon/android/ic_launcher_{background,foreground,monochrome}.png` | `flutter_launcher_icons` adaptive config in `apps/mobile/pubspec.yaml` |
| Play Store | `app-icon/android/play-store-512.png` | Play Console listing |
| Native splash (iOS + Android 12+) | `splash/android12-splash-icon.png` (navy mark) on `#F7F9FC` | `flutter_native_splash` config |
| Web / admin | `web/*` | `apps/admin/public` (copied by the script) |
